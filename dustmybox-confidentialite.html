DustMyBox

Politique de confidentialité

Dernière mise à jour : août 2026

DustMyBox est une application mobile gratuite permettant d'analyser et de nettoyer des boîtes Gmail. Cette politique de confidentialité explique quelles données sont manipulées, comment et pourquoi.

1. Données accédées

DustMyBox accède aux données Gmail suivantes via l'API officielle de Google (OAuth 2.0, scope GMAIL_MODIFY) :

  • L'adresse e-mail de l'expéditeur
  • L'objet du mail
  • La date de réception
  • La taille du message (en octets)
  • Le statut lu / non lu
  • Les identifiants de message (ID Gmail)

Le corps du mail et les pièces jointes ne sont jamais lus ni accédés.

2. Utilisation des données

Les données accédées servent exclusivement à :

  • Regrouper les mails par expéditeur pour faciliter le tri ;
  • Afficher les statistiques de taille et de date ;
  • Supprimer les mails sélectionnés à votre demande explicite.

3. Stockage des données

Toutes les données restent sur votre appareil. DustMyBox ne dispose d'aucun serveur propre.

  • Cache temporaire (2 heures) : métadonnées des mails analysés (expéditeur, taille, date, objet). Effacé automatiquement.
  • Données permanentes : mails et expéditeurs que vous avez explicitement protégés, vos statistiques de tri et vos défis. Conservées tant que l'application est installée.

Aucune donnée n'est transmise à un tiers, ni à l'éditeur de l'application.

4. Partage avec des tiers

DustMyBox utilise les services suivants :

  • Google Gmail API — pour lire les métadonnées et supprimer les mails. Politique de confidentialité Google
  • Google AdMob — pour afficher des publicités. Google peut collecter des identifiants publicitaires selon ses propres règles. Politique de confidentialité Google

Aucune autre donnée n'est partagée avec des tiers.

5. Révocation des permissions

Vous pouvez révoquer l'accès de DustMyBox à votre compte Google à tout moment depuis myaccount.google.com/permissions. Cela ne supprime pas les données stockées localement ; désinstallez l'application pour les effacer.

6. Données des mineurs

DustMyBox n'est pas destinée aux enfants de moins de 13 ans et ne collecte pas sciemment de données les concernant.

7. Vos droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants :

  • Accès : obtenir une copie de vos données ;
  • Rectification : corriger des données inexactes ;
  • Effacement : demander la suppression de vos données ;
  • Opposition : vous opposer au traitement de vos données ;
  • Portabilité : recevoir vos données dans un format structuré.

Pour exercer ces droits : dustmybox.app@gmail.com. Vous pouvez également introduire une réclamation auprès de la CNIL.

8. Mise à jour

Cette politique peut être mise à jour. La version en vigueur est toujours disponible dans l'application et à l'adresse de cette page.

9. Contact

Pour toute question : dustmybox.app@gmail.com
